# Claude-1
First Claude Repository

- `split-the-james.html`: Split the Check (bill-splitting web app)
- [`CastPilot/`](CastPilot/README.md): iPhone app that finds videos on websites and casts them to Chromecast, smart TVs (DLNA), Roku and AirPlay
- [`CastPilotWeb/`](CastPilotWeb/README.md): web version of CastPilot, with AirPlay/Chromecast casting, a "Find videos" bookmark, queue, resume and more. Add it to your Home Screen; no install needed.
